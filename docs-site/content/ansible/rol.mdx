# Eigen rol

Software rechtstreeks op een machine zetten, zonder Docker: dingen die laag
in het netwerk zitten of een eigen machine horen te hebben, zoals AdGuard,
Caddy of PBS. Een rol is meer werk, want jij schrijft de installatiestappen.
Bestaat er een Docker-image van je app, neem dan een
[Docker-app](/docker/toevoegen/).

Voorbeeld: Vaultwarden op een eigen LXC.

<Steps>

#### Zorg dat de machine bestaat

Maak de LXC met [Nieuwe container](/proxmox/container/).

#### Kopieer een bestaande rol

Neem de rol die het meest op de jouwe lijkt. `adguard` is een goed
vertrekpunt: één binary, één config, één dienst.

```bash filename="laptop"
cp -r roles/adguard roles/<naam>
cp playbooks/adguard.yml playbooks/<naam>.yml
```

Pas in `playbooks/<naam>.yml` de naam, `hosts:`, de rol en de tags aan.
In de rol: hernoem de variabelen (`adguard_*` wordt `<naam>_*`) en zet de
beschrijving in `meta/main.yml` goed.

#### Schrijf de installatiestappen

```bash filename="laptop"
$EDITOR roles/<naam>/tasks/main.yml
```

Houd het vaste patroon aan dat alle rollen hier volgen:

1. installeer een vaste versie
2. schrijf de configuratie (en laat die controleren vóór ze actief wordt)
3. zet de dienst aan
4. herstart hem als de configuratie verandert

#### Zet hem in `site.yml`

```bash filename="laptop"
$EDITOR playbooks/site.yml
```

De volgorde telt: eerst waar je dienst van afhangt, daarna je dienst.

#### Eerst een dry run, dan echt

```bash filename="laptop"
ansible-playbook playbooks/<naam>.yml --check --diff   # toont wat er zou veranderen
ansible-playbook playbooks/<naam>.yml                  # doet het echt
```

#### Geef hem een adres

Volg [Alleen een adres](/netwerk/caddy/#alleen-een-adres) om een route toe te voegen.

</Steps>
