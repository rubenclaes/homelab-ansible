# Herstellen

Er is iets stuk en je wil het terug. Kies in de tabel wat er stuk is en volg
dan alleen die pagina, stap voor stap.

<Callout type="info">

## Welk geval ben jij?

| Jouw situatie | Voorbeeld | Ga naar |
| --- | --- | --- |
| Er is **nu niets stuk** | je wil voorbereid zijn | [Vooraf: doe dit nu](/technisch/runbooks/disaster-recovery/vooraf/) |
| Een container is stuk, en er staat niets op dat je niet opnieuw kan maken | `caddy`, `tailscale` | [Container herbouwen](/technisch/runbooks/disaster-recovery/container-herbouwen/) |
| Een container of VM is stuk, en **wat erop stond** moet terug | `adguard`, `semaphore`, `docker`, Home Assistant | [Terugzetten uit back-up](/technisch/runbooks/disaster-recovery/terugzetten/) |

| De Mac mini is kapot of opnieuw geïnstalleerd | nieuwe schijf, macOS opnieuw | [Mac mini is weg](/technisch/runbooks/disaster-recovery/mac-mini/) |
| `pve01` zelf is weg | bootschijf dood, Proxmox van USB opnieuw geïnstalleerd | [pve01 is weg](/technisch/runbooks/disaster-recovery/pve01/) |
| De back-ups op PBS zijn weg of onleesbaar | schijf `vm-hdd` kapot, of de sleutel kwijt | [Tweede kopie](/technisch/runbooks/disaster-recovery/tweede-kopie/) |

terugzetten kan altijd.

**Is er nu niets stuk?** Doe dan eerst [Vooraf: doe dit nu](/technisch/runbooks/disaster-recovery/vooraf/).
Zonder die stappen werkt geen enkel geval hierboven.

## Woorden die je nodig hebt

**Node** — de fysieke machine `pve01` (`192.168.0.14`), met Proxmox erop.

**Guest** — een container (LXC, commando's `pct`) of virtuele machine (VM,
commando's `qm`) op die node. Elke guest heeft een nummer, de *vmid*.

**PBS** — Proxmox Backup Server, VM 100. Hij bewaart de dagelijkse back-ups,
versleuteld, op de schijf `vm-hdd` van pve01 zelf.

**Tweede kopie** — de wekelijkse back-up naar de Mac mini (`macmini-backup`).
Niet versleuteld.

**Vault-wachtwoord** — ontgrendelt de versleutelde bestanden in de repo. Er
zijn er twee: `infra` en `stacks`.

**API-token** — de login waarmee Ansible aan Proxmox vraagt welke machines er zijn.

**Dynamische inventory** — `inventory/homelab.proxmox.yml`: haalt de lijst
guests live uit Proxmox, via dat token.

**Bootstrap** — de eerste keer inloggen als root en de gebruiker `ansible` aanmaken.

**Baseline** — de basisinstellingen die elke Linux-host krijgt (o.a. inloggen
met wachtwoord uit).
