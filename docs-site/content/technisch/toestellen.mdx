# Toestellen

<Callout type="warning">
Gegenereerd uit `devices` in `inventory/group_vars/all/devices.yml`.
Machines mét SSH staan onder [Hosts](/technisch/hosts/) — die komen uit de
inventory, niet uit deze lijst.
</Callout>

Het adres is een reservering die jij in de router zet, niet iets dat hier wordt
afgedwongen. Wat hier wél wordt afgedwongen is alles wat AdGuard erover moet
weten: `roles/adguard` maakt de naam `<toestel>.home.arpa` en
zet het filterbeleid uit het `dns`-blok. Elke host uit de inventory krijgt langs
dezelfde weg `<host>.home.arpa`.

De router blijft handwerk. Een vast adres toekennen is twintig seconden klikken
en gebeurt één keer per toestel; daar is een playbook voor duurder dan het
oplevert.

Er staan nog geen toestellen in de lijst. Voeg er een toe in
`inventory/group_vars/all/devices.yml`; het bestand bevat voorbeelden om te
kopiëren.
