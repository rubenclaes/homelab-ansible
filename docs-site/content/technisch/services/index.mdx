# Diensten

<Callout type="warning">
Gegenereerd uit `caddy_sites` in `inventory/host_vars/caddy/main.yml`, plus
`docker_services_without_route` voor diensten zonder webadres. Bewerk de
inventory, niet deze pagina.
</Callout>

Wat er draait, per machine. Een dienst met een webroute staat op
`https://<naam>.neodata.be`; klik de naam voor het adres, de poort en
de instellingen. De stack linkt naar de machine waar hij op staat.
