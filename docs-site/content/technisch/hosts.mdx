# Hosts

<Callout type="warning">
Gegenereerd uit de samengevoegde map `inventory/`: `00-static.yml` plus de
Proxmox-guests die `homelab.proxmox.yml` live ophaalt. Bewerk de inventory,
niet deze pagina.
</Callout>

| Host | Adres | Groepen | OS |
| --- | --- | --- | --- |
| **macmini** | `192.168.0.26` | macs | macOS 14.6.1 |
| **mbp** | lokaal | macs | macOS 27.0 |
| **pve01** | `192.168.0.14` | linux, proxmox | Debian 13.7 |

Adressen komen live uit Proxmox: het runtime-adres van de guest, niet wat er
in zijn config staat. Twee containers draaien DHCP en kloppen daardoor toch.
