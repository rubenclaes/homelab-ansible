# Toegang afnemen

Iemand hoeft er niet meer bij. Je sluit elke plek af waar je iets gaf:
Pocket ID, NeoGate, Tailscale, WireGuard en Vaultwarden. Alleen een toestel
kwijt, niet de persoon? Zie [Toestel kwijt](/netwerk/toestellen/#een-toestel-is-kwijt-of-weg).

<Steps>

#### Vaultwarden

[vault.neodata.be/admin](https://vault.neodata.be/admin) → **Users** → de
persoon → **Delete**. Als eerste, anders weet je later niet meer dat hij er
nog stond.

#### Pocket ID

[id.neodata.be](https://id.neodata.be) → **Users** → de persoon →
**Disable** (of **Delete**). Dat stopt nieuwe logins. Een sessie die al
openstaat in een app, blijft werken tot ze verloopt; verwijder de persoon dus
ook in de apps waar het telt (Immich, Outline).

#### NeoGate

[neogate.neodata.be](https://neogate.neodata.be) → **Gezin** → `⋯` bij de
persoon:

| Kies | Doet |
| --- | --- |
| **Toegang intrekken** | haalt al zijn accounts weg, de persoon blijft in de lijst |
| **Verwijderen** | hetzelfde, en haalt hem uit de lijst |
| één dienst uitvinken | alleen die ene dienst weg |

Geeft een dienst een foutmelding, vink hem dan opnieuw uit.

#### Tailscale-console

NeoGate trekt alleen de **uitnodiging** in. Had de persoon die al aanvaard,
dan blijft hij lid van de tailnet tot je hem hier weghaalt.

| Scherm | Wat |
| --- | --- |
| [Tailscale admin console](https://login.tailscale.com/admin/users) → **Users** | de persoon → `⋯` → **Remove user** |
| **Machines** | nog toestellen van hem? → **Remove** |

#### WireGuard

UniFi → **Settings** → **VPN** → **VPN Server** → **Neodata VPN** → elk
clientprofiel van die persoon verwijderen.

#### Controleer

De persoon staat niet meer in Pocket ID, NeoGate **Gezin**, Tailscale
**Users** en Vaultwarden, en heeft geen profiel meer in UniFi.

</Steps>
