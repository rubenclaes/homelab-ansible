## Woorden die je nodig hebt

**Drift** — een host die niet meer overeenkomt met wat de repo beschrijft.

**Converge** — `site.yml` draaien, zodat elke host weer gelijk is aan de repo.

**Template** — een job in Semaphore: een playbook, argumenten en eventueel een schema (cron).

**Demper** — een regel in de host_vars die een melding in het rapport bewust stilzet, mét reden.

**Hypervisor** — de fysieke machine waar de rest op draait: `pve01`. Gaat die
uit, dan gaat alles uit.

**Guest** — een VM of LXC *op* `pve01`: `adguard`, `caddy`, `docker`, `pbs`,
`semaphore`, `tailscale`, `docker-grafana-stack`. Dat is de groep `guests`.

**Formula** — een Homebrew-*pakket* op een Mac, commandoregel-gereedschap
zoals `jq` of `ffmpeg`.

**Cask** — een Homebrew-*app* op een Mac, iets met een venster zoals Spotify
of VLC.

**Bridge** — de virtuele netwerkkaart van pve01 (`vmbr0`, `vmbr1`) waar de
guests en de node zelf aan hangen.

**Resolver** — de DNS-server die een toestel vraagt "welk adres hoort bij deze
naam?". Hier is dat AdGuard in ct 107 (`192.168.0.29`).

**Tailnet** — alle toestellen die via Tailscale met elkaar verbonden zijn.
