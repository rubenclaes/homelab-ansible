# Gast op bezoek

Iemand komt langs en wil iets gebruiken. Voor het meeste heb je niets te doen.

| De gast wil… | Wat je doet |
| --- | --- |
| internet | het wachtwoord van het gewone wifi geven |
| bestanden uitwisselen met jou | [pairdrop.neodata.be](https://pairdrop.neodata.be) openen, op allebei de toestellen. Werkt meteen, zolang jullie op hetzelfde wifi zitten |
| foto's van een feest krijgen | in Immich een **deellink** maken van het album. Geen account nodig, maar werkt alleen op het wifi thuis: Immich staat niet op internet |
| blijvend films kijken of foto's bewaren | een account via NeoGate: [Iemand diensten geven](/runbooks/toegang/diensten-geven/) |
| er van bij hem thuis bij kunnen | [Iemand VPN geven](/runbooks/toegang/vpn-geven/) |

<Callout type="warning">
Er is **geen gastennetwerk**. Een gast zit op hetzelfde netwerk als pve01, de
Macs en alle diensten. Zijn toestel ziet ze dus, al moet hij voor de meeste nog
inloggen. Een apart gastennetwerk staat op de TODO.
</Callout>
