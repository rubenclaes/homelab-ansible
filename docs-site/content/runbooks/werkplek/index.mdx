# Werkplek

Alles wat je op je laptop (`mbp`) doet om vlot met de homelab te werken:
de repo klaarzetten, hosts bij naam bereiken, korte shell-commando's, en
veilig playbooks draaien.

## Welk geval ben jij?

| Jouw situatie | Voorbeeld | Ga naar |
| --- | --- | --- |
| Je wil vanaf een **nieuwe laptop** playbooks draaien en `ssh caddy` typen | nieuwe MacBook, de `mbp` opnieuw geïnstalleerd, of `~/.zshrc` kwijt | [Laptop klaarzetten](/runbooks/werkplek/laptop/) |
| Er is een **nieuwe machine** bij en `ssh <naam>` werkt nog niet | net een LXC gebouwd met `new-guest.yml` | [Nieuwe machine bij naam](/runbooks/werkplek/nieuwe-machine/) |
| Je wil een **afkorting** toevoegen of aanpassen in je shell | een alias zoals `hl` of `ap` | [Shell-afkorting aanpassen](/runbooks/werkplek/afkorting/) |
| Je wil **snel iets weten** van een host, zonder in te loggen | welke Caddy-versie draait er, leven ze nog | [Snel iets vragen](/runbooks/werkplek/snel-vragen/) |
| Je wil een playbook draaien, maar eerst **zien wat het doet** | `site.yml` na een wijziging in de inventory | [Veilig een playbook proberen](/runbooks/werkplek/playbook-proberen/) |
| Je hebt net een playbook gedraaid: **wat nu?** | na `caddy.yml`, `update.yml`, `stacks.yml` | [Na een run](/runbooks/werkplek/na-een-run/) |

<Callout type="info">
Nog nooit met deze repo gewerkt op deze laptop? Begin bij
[Laptop klaarzetten](/runbooks/werkplek/laptop/). Zonder de
`ansible`-sleutel en de vault-wachtwoorden werkt geen enkel ander geval.
</Callout>

## Woorden die je nodig hebt

**Dotfiles** — je persoonlijke configbestanden (`~/.zshrc`, `~/.ssh/config`, `~/.gitconfig`). Het playbook `dotfiles.yml` schrijft ze voor je.

**Inventory** — de lijst van alle machines, in `inventory/`. De Proxmox-guests komen automatisch uit de Proxmox-API.

**Dynamische inventory** — `inventory/homelab.proxmox.yml`: haalt de lijst guests live uit Proxmox, via een API-token.

**Vault-wachtwoord** — ontgrendelt de versleutelde bestanden in de repo. Er zijn er twee: `infra` en `stacks`.

**Ad-hoc-commando** — één commando op een host via `ansible`, zonder playbook.
