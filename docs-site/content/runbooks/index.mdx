# Runbooks

Wat je doet, stap voor stap. Wat er is, staat onder [Homelab](/homelab/).

| Ik wil… | Ga naar |
| --- | --- |
| een toestel op het netwerk, iemand toegang geven of afnemen, een site blokkeren | [Toestellen en toegang](/runbooks/toegang/) |
| mijn laptop klaarzetten, of vlot met de repo werken | [Werkplek](/runbooks/werkplek/) |
| een nieuwe VM of container op pve01 | [Nieuwe machine](/runbooks/nieuwe-guest/) |
| een nieuwe dienst of een adres voor iets | [Dienst toevoegen](/runbooks/dienst-toevoegen/) |
| alles bijwerken | [Updates](/runbooks/updates/) |
| nakijken of alles gezond is, schijf vol, drift | [Onderhoud](/runbooks/onderhoud/) |
| iets aan bridges, DNS-servers, Tailscale of de VPN veranderen | [Netwerk en Proxmox](/runbooks/netwerk/) |
| iets is stuk of weg | [Herstellen](/runbooks/disaster-recovery/) |

Elke runbook begint met een tabel **Welk geval ben jij?**. Het waarom staat
telkens apart onder **Goed om te weten**.
