# Netwerk en Proxmox

Iets aan het netwerk of aan de Proxmox-node zelf. Geen van deze dingen zit in
`site.yml`: je draait ze bewust, met de hand.

## Welk geval ben jij?

| Jouw situatie | Voorbeeld | Ga naar |
| --- | --- | --- |
| Je wil een **IP-adres of bridge** van de hypervisor aanpassen | `vmbr1` krijgt een ander adres | [Bridges van pve01 wijzigen](/runbooks/netwerk/bridges/) |
| Na een herbouw starten guests **niet mee op** als pve01 opstart | na een restore staat de helft op `onboot: 0` | [Guests mee laten opstarten](/runbooks/netwerk/autostart/) |
| Je wil een **pc of NAS** op Tailscale zetten | de pc van je ouders, een Raspberry Pi | [Tailscale-sleutel voor een apparaat](/runbooks/netwerk/tailscale-sleutel/) |
| Een host moet een **andere DNS-server** gebruiken | `caddy` wijst nog naar een oude resolver | [DNS-server van een host omzetten](/runbooks/netwerk/dns-server/) |
| Je wil nakijken of je **van buitenaf** nog binnenkomt | de VPN op je iPhone doet niets meer | [De VPN nakijken](/runbooks/netwerk/vpn/) |
| Je wil weten **hoe DNS en de VPN nu in elkaar zitten** | "welke resolver gebruikt `docker`?" | [Hoe het netwerk nu staat](/homelab/netwerk/) |

## Woorden die je nodig hebt

**Bridge** — de virtuele netwerkkaart van pve01 (`vmbr0`, `vmbr1`) waar de
guests en de node zelf aan hangen.

**Resolver** — de DNS-server die een toestel vraagt "welk adres hoort bij deze
naam?". Hier is dat AdGuard in ct 107 (`192.168.0.29`).

**Tailnet** — alle toestellen die via Tailscale met elkaar verbonden zijn.
