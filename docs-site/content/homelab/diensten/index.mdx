# Diensten

Wat er draait, per machine. Een dienst met een webroute staat op
`https://<naam>.neodata.be`; klik de naam voor het adres, de poort en
de instellingen. De stack linkt naar de machine waar hij op staat.

Zo komt een bezoek aan een dienst binnen:

1. AdGuard stuurt élke naam onder `neodata.be` naar Caddy. Dat is één
   wildcard, dus een nieuwe dienst heeft geen eigen DNS-regel nodig.
2. Caddy zorgt voor het certificaat en zoekt in `caddy_sites` naar welke
   machine en poort hij moet doorsturen.
3. Een dienst zonder webroute, zoals RustDesk, slaat Caddy over: de app praat
   rechtstreeks met de machine.
