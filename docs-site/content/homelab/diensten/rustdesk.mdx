# rustdesk

RustDesk — eigen server voor remote support (ID en relay)

| Eigenschap | Waarde |
| --- | --- |
| URL | — geen webroute |
| Adres | `192.168.0.15` |
| Host | [docker](/homelab/machines/#docker) |
| Poorten | `21115/tcp`, `21116/tcp`, `21116/udp`, `21117/tcp` |
| Stack | [rustdesk](/homelab/machines/#docker) |

## Gebruiken

Geen webpagina: de RustDesk-app praat rechtstreeks met de server. Zet in de app bij Netwerk de ID-server op het adres van deze host en vul de publieke sleutel in (`id_ed25519.pub` in de datamap van de stack). Buiten het LAN werkt hij alleen als de router deze poorten doorstuurt.

<small>Deze pagina wordt automatisch gemaakt. Iets fout? Pas `docker_services_without_route` aan in de host_vars van `docker` (`inventory/host_vars/docker/main.yml` of `docker.yml`).</small>
