Inloggen gaat alleen via [Pocket ID](https://id.neodata.be) (knop **Inloggen
met Pocket ID**); de wachtwoord-login staat uit sinds iedereen over is. Wie erin
mag: [Pocket ID → Per app](/mensen/pocket-id/#per-app).

Op de telefoon stap je over door uit te loggen en opnieuw in te loggen met
dezelfde knop.

## Een instelling aanpassen

De instellingen staan in git, niet in de web-UI: onder **Administration →
Settings** kan je ze alleen lezen. Aanpassen doe je in de `containers`-repo,
`stacks/media/docker-compose.yml`, onderaan bij `configs.immich`. Alleen wat
afwijkt van de standaard staat erin; de rest is de standaard van Immich.

Daarna pushen en de stack opnieuw uitrollen (`stacks.yml`).

## Goed om te weten

### Een nieuwe beheerder

Wie in `admin` zit, krijgt bij de **eerste** login meteen de rol admin (de
claim `immich_role` van die groep). Een bestaand account houdt zijn rol:
Immich leest de claim alleen bij het aanmaken.

### De database is VectorChord

Sinds 07-10 draait `immich-postgres` op `ghcr.io/immich-app/postgres` met
VectorChord, niet meer op `tensorchord/pgvecto-rs`: Immich v3 kan niet met
pgvecto.rs. Immich zette de database bij het opstarten zelf om. Daarna nooit
meer terug naar een Immich onder v1.133.0.

### Een nieuwe major van Immich

Renovate maakt er een PR van, ook als het alleen een nieuwe digest van de tag
`release` is: die tag springt mee naar een nieuwe major. Lees eerst de
breaking changes in de release notes, en leg ze naast de stack in
`containers` (database, env-variabelen, `configs.immich`).
