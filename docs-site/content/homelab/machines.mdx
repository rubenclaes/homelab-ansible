# Machines

<Callout type="warning">
Gegenereerd door `playbooks/docs.yml` uit de inventory: `00-static.yml`, de
Proxmox-guests die `homelab.proxmox.yml` live ophaalt, `pve_lxcs` en elke
`docker_stacks_list`. Bewerk de inventory, niet deze pagina.
</Callout>

Alles waar iets op draait, op één pagina. Per machine zie je het adres, welke
[diensten](/homelab/diensten/) erop staan en - bij een Docker-machine - in
welke stack elke dienst zit. Een stack is één compose-bestand met één of meer
diensten erin.

---

Een verdwenen LXC-container wordt opnieuw gemaakt uit `pve_lxcs` in
`inventory/group_vars/proxmox/lxcs.yml`, met template
`local:vztmpl/debian-13-standard_13.1-2_amd64.tar.zst` op bridge `vmbr0`. Een
bestaande container wordt nooit aangeraakt.
